# 3CX V20 Integration Notes

> ข้อมูลอ้างอิงเบื้องต้น (ก.ย. 2026) — AI ต้องตรวจกับ Endpoint Specification ทางการของ 3CX ก่อน implement และบันทึก payload จริงที่ทดสอบได้ไว้ในไฟล์นี้

## Version

- Target: **3CX V20, latest update (Update 10 as of Sep 2026)**
- vCRMOCR: **not used**. Screen-pop and call reports are built inside vCRM.

## Integration surfaces

| Surface                                        | Use in vCRM                                                                                                    | Auth                                                                                    | License                                 |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- | --------------------------------------- |
| CRM Integration Template (3CX calls vCRM REST) | Contact lookup by number, create contact, call journaling, chat journaling, open contact URL in 3CX Web Client | Tenant API key (in template)                                                            | All editions supporting CRM integration |
| Call Control API (REST + WebSocket)            | Realtime call events → screen-pop, click-to-call, transfer                                                     | OAuth2 client credentials (Client ID + API key from Admin Console → Integrations → API) | **8SC+**                                |
| Configuration API / XAPI (REST/OData)          | Sync users/extensions, queues, departments                                                                     | OAuth2 client credentials → `POST /connect/token`, token valid 60 min                   | **8SC+**                                |

## Degradation rules

- No 8SC+ → only CRM Template: lookup + journaling work; screen-pop via 3CX Web Client URL `/agent/screen-pop?phone=[Number]&callid=[CallID]`; no click-to-call; manual extension mapping.
